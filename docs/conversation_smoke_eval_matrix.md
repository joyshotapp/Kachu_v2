# Kachu+ 對話上線評測集

版本：1.0
日期：2026-05-12
用途：production smoke、人工驗收、對話品質回歸比較

執行方式：

python scripts/smoke_conversation_prod.py

若要指定 tenant 或 LINE user：

python scripts/smoke_conversation_prod.py --tenant-id <tenant_id> --line-user-id <line_user_id>

## 1. 評測原則

每題都要同時檢查：

1. 是否先回應老闆真正問題。
2. 是否承接已知脈絡，而不是像第一次見面。
3. 是否避免 generic clarify。
4. 是否有明確下一步。
5. 是否語氣專業且有人味。

## 2. 基本四類 smoke

### A. Greeting

題目：你好

預期：

1. 直接自然招呼。
2. 不呼叫顧問長答。
3. 不回固定澄清。

### B. Capability overview

題目：你能做什麼？

預期：

1. 清楚列出能力範圍。
2. 要給具體例句。
3. 不回 generic clarify。

### C. Consult

題目：你覺得我接下來該先衝來客還是先衝回購？

預期：

1. 先明確給判斷。
2. 至少有兩個具體理由。
3. 最後有最短下一步。
4. 不可只回「讓我想想」這類空話。

### D. Clarify

題目：最近流量掉很多

預期：

1. 回具體澄清問題。
2. 問題要貼合流量語境，例如報告、數字、原因。
3. 不可回通用澄清句。

## 3. 擴充驗收題庫

### 3.1 評論處理

題目：有個評論

預期：

1. 問是否直接代回或先判斷處理方式。
2. 不可只說「請再說清楚」。

### 3.2 顧客流失

題目：最近很多老客都沒回來

預期：

1. 回覆要明確落在客人回流或流失分析。
2. 若澄清，問題要指向名單查詢或原因分析。

### 3.3 內容方向

題目：我想做母親節，但不知道怎麼切角度

預期：

1. 直接進諮詢，不可掉 generic clarify。
2. 回覆要給 2 到 3 個方向，不是純追問。

### 3.4 店務更新

題目：明天提早打烊

預期：

1. 直接辨識為 execute。
2. 不應進 consult 或 clarify。

### 3.5 情緒承接

題目：最近生意很差，我有點焦慮

預期：

1. 先接住情緒。
2. 再問一個最有區分力的問題，或先給可行方向。
3. 不可冷冰冰直接分類。

### 3.6 延續任務

題目：那篇草稿太硬了，改柔一點

前置條件：tenant 已存在最近草稿任務。

預期：

1. 承接前一個 task，不當成新需求。
2. metadata 應帶 follow-up 訊號。
