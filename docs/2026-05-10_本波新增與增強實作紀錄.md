# 2026-05-10 本波新增與增強實作紀錄

版本：1.0  
日期：2026-05-10  
範圍：本輪針對內容企劃、Meta 互動、審核發布、migration 與部署文件的新增與強化

---

## 1. 本波完成範圍

這一輪完成的重點不是單點修 bug，而是把幾條原本只有半套的流程補成可執行 runtime：

1. 內容企劃不再只停在企劃 JSON，而是能持久化、排程、產草稿、進審核、發布。
2. Meta 不再只有 OAuth 與 insights，已補上 inbound webhook、互動事件入庫、回覆草稿與代回流程。
3. 非 AgentOS 本地流程現在也能走完整的 approve / reject / edit，而不是卡在既有 approval bridge 假設。
4. migration、部署文件、測試與回歸驗證已同步補齊。

---

## 2. 內容企劃相關新增

### 2.1 持久化與排程 runtime

新增能力：

1. `ContentPlanTable`、`ContentPlanItemTable` 已正式納入 schema。
2. 新增 `ContentPlanService`，負責建立企劃、建立 item、產生待發布草稿。
3. 新增 `ContentPlanScheduler`，可掃描 due item 並轉成待審核草稿。
4. due item 轉草稿後，會建立本地 `pending approval`，workflow type 為 `kachu_planned_content`。

行為結果：

1. 老闆先要企劃，再說「照這個企劃寫」時，現在會進到可審核的本地草稿流程。
2. 企劃排程到點後，系統可自動推播待確認草稿，而不是只停在資料層。

涉及檔案：

1. `src/kachu_plus/content_plans.py`
2. `src/kachu_plus/persistence/tables.py`
3. `src/kachu_plus/persistence/repository.py`
4. `src/kachu_plus/tools_router.py`
5. `src/kachu_plus/line/webhook.py`
6. `src/kachu_plus/main.py`

### 2.2 本地發布能力

新增能力：

1. 抽出共用 publishing helper，避免內容發布邏輯散落在 endpoint 與 webhook。
2. `kachu_planned_content` 本地 approve 後可直接發布，不再依賴 AgentOS approval id。
3. publish 後會回寫 `PublishedContentRecordTable`、`PendingApprovalTable` 與 `ContentPlanItemTable` 狀態。

涉及檔案：

1. `src/kachu_plus/publishing.py`
2. `src/kachu_plus/tools_router.py`
3. `src/kachu_plus/line/webhook.py`

## 3. Meta 互動與回覆相關新增

### 3.1 Meta webhook 與事件入庫

新增能力：

1. `GET /meta/webhook`：支援 verify challenge。
2. `POST /meta/webhook`：支援 ingest Meta inbound events。
3. comment 與 message 事件可 dedupe、解析 page id、反查 tenant、寫入 `ExternalEngagementTable`。
4. `MetaGraphClient` 新增 `reply_to_comment` 與 `send_page_message`。

行為結果：

1. 系統現在能接 Facebook 留言與私訊，而不再只有 outbound 發文/insights。
2. 收到互動後，會先起草回覆，再轉為待老闆確認的本地審核流程。

涉及檔案：

1. `src/kachu_plus/meta.py`
2. `src/kachu_plus/persistence/repository.py`
3. `src/kachu_plus/persistence/tables.py`

### 3.2 Meta 回覆審核與代回

新增能力：

1. 新增 workflow type `kachu_meta_reply`。
2. LINE postback 現在可本地處理 Meta reply 的 approve / reject / edit。
3. approve 後可直接透過 Meta Graph API 代回 comment 或 page message。
4. 回覆結果會回寫 published record 與 external engagement 狀態。

涉及檔案：

1. `src/kachu_plus/line/webhook.py`
2. `src/kachu_plus/publishing.py`
3. `src/kachu_plus/meta.py`
