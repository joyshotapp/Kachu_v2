# Kachu+ 商家開通填值工作表

版本：v1.0  
更新日期：2026-05-09  
用途：工程、BD/CS、導入協作時統一收集正式開通所需欄位

---

## 使用方式

這份表單分成三層：

1. 系統層：只要一套，給 production 環境使用
2. Tenant 開通層：每個商家都要填，用於 POST /admin/tenants
3. Connector 層：商家要串 Google / Meta 時再填

---

## A. 系統層環境變數工作表

這一段對應 [.env.prod.example](./../.env.prod.example)。

| Key | 必填 | 目前值 / 待填 | 備註 |
|---|---|---|---|
| POSTGRES_PASSWORD | 是 | `待填` | 建議 `openssl rand -hex 16` |
| FIELD_ENCRYPTION_KEY | 是 | `待填` | 建議 Fernet 產生 |
| ADMIN_API_TOKEN | 是 | `待填` | Admin API Bearer token |
| GOOGLE_AI_API_KEY | 建議是 | `待填` | photo analyze / FAQ / 顧問回覆主力 |
| OPENAI_API_KEY | 選填 | `待填` | LLM 備援 |
| GOOGLE_OAUTH_CLIENT_ID | Google 串接時必填 | `待填` | refresh token 需要 |
| GOOGLE_OAUTH_CLIENT_SECRET | Google 串接時必填 | `待填` | refresh token 需要 |
| LITELLM_MODEL | 是 | `gemini/gemini-2.0-flash` | 通常沿用預設 |
| CONSULTANT_LLM_MODEL | 是 | `gemini/gemini-2.0-flash` | 通常沿用預設 |

### `.env.prod` 可直接複製範本

```dotenv
POSTGRES_PASSWORD=待填
FIELD_ENCRYPTION_KEY=待填
ADMIN_API_TOKEN=待填

GOOGLE_AI_API_KEY=待填
OPENAI_API_KEY=待填
LITELLM_MODEL=gemini/gemini-2.0-flash
CONSULTANT_LLM_MODEL=gemini/gemini-2.0-flash

GOOGLE_OAUTH_CLIENT_ID=待填
GOOGLE_OAUTH_CLIENT_SECRET=待填
GOOGLE_SERVICE_ACCOUNT_JSON=

SLEEP_SYNC_ENABLED=true
SLEEP_SYNC_RUN_ON_STARTUP=true
SLEEP_SYNC_INTERVAL_SECONDS=86400
```

## B. Tenant 開通工作表

這一段對應 `POST /admin/tenants`。

| 欄位 | 必填 | 待填值 | 說明 |
|---|---|---|---|
| name | 是 | `待填` | 商家名稱 |
| industry_type | 建議是 | `待填` | 中文即可，例如 `咖啡店` |
| address | 建議是 | `待填` | 實體地址或 `網路` |
| plan | 否 | `trial` | 目前可先沿用預設 |
| owner_line_user_id | 是 | `待填` | 老闆本人 LINE user_id，通常以 `U` 開頭 |
| owner_display_name | 否 | `待填` | 不填時可用店名 |
| line_channel_id | 是 | `待填` | LINE Developers Console |
| line_channel_secret | 是 | `待填` | LINE Developers Console |
| line_channel_access_token | 是 | `待填` | Messaging API 長 token |

### Tenant 開通 payload 範本

```json
{
  "name": "待填",
  "industry_type": "待填",
  "address": "待填",
  "plan": "trial",
  "owner_line_user_id": "待填",
  "owner_display_name": "待填",
  "line_channel_id": "待填",
  "line_channel_secret": "待填",
  "line_channel_access_token": "待填"
}
```

### Tenant 開通 curl 範本

```bash
curl -X POST https://plus.kachu.tw/admin/tenants \
  -H "Authorization: Bearer <ADMIN_API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d @tenant-provision.json
```

## C. Google Business Connector 工作表

這一段對應 `PUT /tenants/{tenant_id}/google-business/connector`。

| 欄位 | 必填 | 待填值 | 說明 |
|---|---|---|---|
| account_label | 否 | `Google Business` | 顯示名稱 |
| account_id | 是 | `待填` | 例如 `accounts/123456789` |
| location_id | 是 | `待填` | 例如 `locations/987654321` |
| access_token | 是 | `待填` | Google Business API token |
| refresh_token | 強烈建議 | `待填` | 否則 token 過期後要人工重設 |
| expires_at | 建議 | `待填` | Unix timestamp，例如 `1760000000` |

### Google connector payload 範本

```json
{
  "account_label": "Google Business",
  "account_id": "accounts/待填",
  "location_id": "locations/待填",
  "access_token": "待填",
  "refresh_token": "待填",
  "expires_at": 1760000000
}
```

### Google connector curl 範本

```bash
curl -X PUT https://plus.kachu.tw/tenants/<TENANT_ID>/google-business/connector \
  -H "Content-Type: application/json" \
  -d @google-connector.json
```

## D. Meta Connector 工作表

這一段對應 `PUT /tenants/{tenant_id}/meta/connector`。

| 欄位 | 必填 | 待填值 | 說明 |
|---|---|---|---|
| account_label | 否 | `Meta` | 顯示名稱 |
| access_token | 是 | `待填` | Graph API token |
| fb_page_id | Meta 發布/insights 時建議必填 | `待填` | Facebook Page ID |
| ig_user_id | IG 發布/insights 時建議必填 | `待填` | Instagram Business User ID |
| fb_access_token | 選填 | `待填` | 若 Facebook 與 IG token 分離 |
| expires_at | 建議 | `待填` | Unix timestamp |
| recent_fb_post_id | 選填 | `待填` | 做 insights 比對用 |
| recent_ig_media_id | 選填 | `待填` | 做 insights 比對用 |

### Meta connector payload 範本

```json
{
  "account_label": "Meta",
  "access_token": "待填",
  "fb_page_id": "待填",
  "ig_user_id": "待填",
  "fb_access_token": "待填",
  "expires_at": 1760000000,
  "recent_fb_post_id": "",
  "recent_ig_media_id": ""
}
```

### Meta connector curl 範本

```bash
curl -X PUT https://plus.kachu.tw/tenants/<TENANT_ID>/meta/connector \
  -H "Content-Type: application/json" \
  -d @meta-connector.json
```
